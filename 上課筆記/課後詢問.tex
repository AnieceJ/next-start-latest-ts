Image是Next優化圖片的自帶套件,
如果在map裡面直接加入Image會跳錯(Next不允許連外, 這裡示範檔是連結外部網路圖片的)
要改next.config.ts做設定(允許)

(next.config.ts)設定:
import type { NextConfig } from 'next';

const nextConfig: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'images.unsplash.com',
      },
    ],
  },
};

export default nextConfig;
