=== key屬性值與map使用搭配 ===
希望在網頁上呈現兩個p, 放在陣列裡面, 這方法叫做清單項目
要加key(否則跳出警告), 問ai
(老師說對React來說, 他覺得這些都是一樣的東西(如兩個li,兩個p等等),所以需要給他們身分證)

嵌入陣列搭配 map ⽅法，其中回傳項目必加 key 屬性值:

陣列資料會使用陣列的 map 方法，搭配例如 <li> 、 <td> 等列表標記，作展開
和調整每個項目的渲染應用。JSX 對於陣列值會直接組合為字串(類似array.join('') )來渲染。

key 是"必要的" React 需要 key 值，在進行列表項目處理(刪除/修改/新增...)時
的最佳化使用，它與效能最佳化、程式運作有極大關聯，不可以省略。

TypeScript 提供陣列和 key 屬性的型別檢查
